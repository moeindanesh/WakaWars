# WakaWars

A local-first coding leaderboard for friends. A macOS menu-bar app shares each user's WakaTime daily/weekly hours and ranks them against friends and group members.

## Language

**Honor Title**:
The short, flavorful text label shown under a username on the leaderboard (e.g. "Emperor of Weeks"). It is a creative *title string* — not an image or icon. Going forward it is generated by an AI model from a user's coding signal, replacing the fixed achievement-to-title map.
_Avoid_: Badge (ambiguous — see below), rank label

**Badge (UI chip)**:
A small inline UI pill next to a username, e.g. the "YOU" marker. Distinct from an Honor Title. When the user says "user badges" they mean the **Honor Title**, not this chip.

**Competition**:
Whether a user is included in the ranked leaderboard. A user can leave (be excluded) or join (be included) the competition; persisted as `is_competing`.
_Avoid_: League membership

**Daily Leaderboard / Weekly Leaderboard**:
The ranked list of competing users for a given day (Today) or week. "Today" and "Week" are the two tabs of the same leaderboard.

**Achievement**:
A milestone unlocked by hitting a coding threshold (e.g. 8h in a day, 40h in a week). Awarded automatically during sync and stored in the database. The achievements *surface* is being removed from the UI, but achievements continue to be awarded and stored.

**History (Previous Days)**:
A browsable archive of past-day leaderboards. A user opens a day and sees that day's full ranked board (the same row UI as Today), reached from its own surface rather than the Today/Week tabs.

## Removed-from-UI concepts (still in the database)

**Skin**:
A cosmetic theme a user can equip; styles their leaderboard row. Being removed from the UI but kept in the database.

**Coin**:
In-app currency awarded for daily rank and spent in the store. Being removed from the UI but kept in the database.

**Store**:
The shop where Skins are bought with Coins. Being removed from the UI.
